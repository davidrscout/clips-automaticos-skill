# Clips automáticos — skill instalable

Skill para montar pipelines locales gratuitos que convierten vídeos largos en clips verticales con subtítulos y los publican en TikTok/YouTube Shorts, con estilo independiente por cuenta.

- La skill fuente está en `skills/clips-automaticos`; sus referencias y plantilla mandan sobre ejemplos genéricos.
- En Windows el instalador es `powershell -ExecutionPolicy Bypass -File instalar_skill.ps1`. Kimi Code también lee `~/.agents/skills`, pero cualquier cambio del instalador debe probarse sin sobrescribir configuraciones existentes.
- Entrevistar antes de instalar: cuentas, redes, horas, fuentes y estilo de cada cuenta. Previa de cada estilo antes de programar/publicar.
- Chrome usa perfiles separados del principal. No publicar durante una simple prueba de instalación. Avisar sobre copyright: vídeos propios, con permiso o licencia compatible.
